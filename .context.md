Raiz do CrIA Treino: SaaS Next.js 16 de treinos personalizados gerados com IA para professores. Contém o app em `src/`, o schema Prisma em `prisma/`, automações em `scripts/` e testes em `tests/`.

## Summary

- README.md — stack, setup local, variáveis de ambiente, segurança, billing, admin e runbook de produção (Vercel + Neon)
- package.json — scripts npm, engines (Node >= 22.12), dependências (Next 16, React 19, Prisma 7, next-intl, Stripe, Resend, OpenAI SDK, jsPDF, Zod)
- next.config.ts — plugin next-intl + cabeçalhos de segurança em todas as respostas (HSTS só em produção)
- prisma7.config.ts — config do Prisma 7 (schema, migrações, seed, DATABASE_URL)
- tsconfig.json — TypeScript com alias de caminho `@/*` → `src/*`
- eslint.config.mjs — ESLint flat config (next/core-web-vitals + typescript), ignora artefatos de teste
- playwright.config.ts — Playwright (Chromium, 1 worker, exige dev server ativo)
- AGENTS.md / CLAUDE.md — regras para agentes (CLAUDE.md aponta para AGENTS.md)
- opencode.json — config do harness OpenCode
- skills-lock.json — lockfile dos skills de agente instalados (ex.: skills Prisma)
- .env.example — template documentado das variáveis de billing/e-mail (o `.env` real é local e gitignored)
- .gitignore / .vercelignore / .ignore — regras de ignorados (git, Vercel, ripgrep)
- next-env.d.ts / tsconfig.tsbuildinfo — artefatos gerados, gitignored
- messages/ — mensagens i18n (pt-BR, en-US)
- prisma/ — schema, migrações e seed
- src/ — aplicação Next.js (App Router com `[locale]`)
- scripts/ — smoke tests e automações de Stripe/i18n
- tests/ — testes de UI (Playwright)
- public/ — SVGs padrão do Next
- .github/workflows/ — CI (typecheck, lint, i18n, E2E, UI)
- docs/ — mapa de features (FEATURE-MAP.md)

## Constraints

- MUST NOT commit o `.env` (gitignored; `.env.example` é o único versionado).
- O build (`npm run build`) roda `prisma generate` antes de `next build` — o client em `src/generated/prisma` não fica no repositório.
- `package.json` exige Node >= 22.12 (a Vercel usa esse piso).

## Guidance

- Deploys e operação seguem o runbook do README, seção "Produção (Vercel + Neon)".
- Antes de mexer em código de agente, leia AGENTS.md e o skill relevante em `.agents/skills/`.
