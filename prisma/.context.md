Camada de dados: schema Prisma 7 (PostgreSQL), migrações SQL e seed do catálogo de exercícios e contas demo. O client gerado sai para `src/generated/prisma` (gitignored).

## Summary

- schema.prisma — modelos: User (papel, plano Stripe, sessionVersion, vínculo professor/aluno), RateLimit, UsageRecord, AthleteProfile, Workout, WorkoutDay, WorkoutExercise, Exercise, Assignment, AdminSetting, PasswordReset
- seed.ts — seed idempotente: upsert do catálogo e (fora de produção) contas demo com senha `demo12345`
- seed-data/exercises.ts — catálogo de 101 exercícios (nome PT/EN, grupo muscular, equipamento, avisos)
- migrations/ — migrações SQL aplicadas em ordem
- ../prisma7.config.ts — config do Prisma 7 que aponta para este diretório

## Constraints

- MUST rodar `npm run db:generate` (ou o build) após mudar o schema — o client não é versionado.
- Em produção o seed MUST rodar com `NODE_ENV=production` para omitir as contas demo.

## Guidance

- Mudanças de schema entram por `npm run db:migrate` (dev) e são aplicadas com `npm run db:deploy` no runbook de produção.
