Árvore de páginas com locale na URL. O layout valida o locale (404 para desconhecido), monta o `NextIntlClientProvider` e as fontes. Páginas protegidas checam a sessão e redirecionam para `/login`.

## Summary

- layout.tsx — `<html lang>`, metadados traduzidos, provider de mensagens
- page.tsx — landing pública (hero, features, como funciona, CTA)
- not-found.tsx — 404 estilizado e localizado
- [...rest]/ — catch-all que chama `notFound()` para URLs inexistentes
- login/ , register/ — autenticação
- forgot-password/ , reset-password/ — recuperação de senha
- dashboard/ — painel do usuário
- billing/ — planos e assinatura (autoatendimento do professor)
- students/ — gestão de alunos (professor)
- workouts/ — wizard (`new/`) e página do treino (`[id]/`)
- admin/ — painel administrativo (role ADMIN)

## Constraints

- Páginas que consultam dados do usuário MUST ser dinâmicas (`export const dynamic = "force-dynamic"`) — o cookie de sessão impede cache estático.
