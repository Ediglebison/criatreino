Webhook do Stripe que sincroniza o plano do usuário.

## Summary

- route.ts — valida a assinatura HMAC com `STRIPE_WEBHOOK_SECRET` (aceita lista separada por vírgula); trata `checkout.session.completed`, `customer.subscription.updated` e `customer.subscription.deleted` para gravar `User.plan` e os ids de customer/assinatura

## Constraints

- O corpo bruto (`request.text()`) MUST ser usado na verificação de assinatura — JSON parseado invalida o HMAC.
