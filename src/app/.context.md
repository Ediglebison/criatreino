Raiz do App Router. Todo conteúdo de página fica sob `[locale]` (pt-BR sem prefixo, `/en-US/...`); os handlers REST ficam sob `api/`.

## Summary

- [locale]/ — páginas do app (landing, auth, dashboard, alunos, wizard, treinos, admin)
- api/ — route handlers REST (auth, students, profiles, workouts, exercises, billing, admin, health)
- globals.css — tema global do Tailwind (importado pelo layout do locale)
- favicon.ico — ícone padrão do template

## Guidance

- A proteção de rotas de página começa em `src/proxy.ts`; cada rota de API repete a checagem de sessão.
