Código da aplicação Next.js 16 (App Router, Turbopack) com React 19. Alias `@/*` aponta para `src/*` (tsconfig). Camadas: rotas/páginas em `app/`, UI em `components/`, infraestrutura em `lib/`, i18n em `i18n/`.

## Summary

- app/ — páginas do App Router (`[locale]`) e handlers de API (`api/`)
- components/ — componentes React (cliente e servidor)
- lib/ — serviços e utilitários (auth, billing, workout, db, e-mail, rate limit)
- i18n/ — configuração do next-intl (routing, request, navigation)
- generated/ — Prisma Client gerado (gitignored; rode `npm run db:generate`)
- proxy.ts — middleware do Next 16: i18n + proteção de rotas + CSP com nonce
- instrumentation.ts — validação de variáveis de ambiente no boot do servidor
- app/globals.css — tema Tailwind 4 (paleta "ember" escura)

## Constraints

- Handlers de API MUST validar sessão e permissão eles mesmos — o proxy não cobre `/api` (exceto `GET /api/health`, que é público de propósito).
