Componentes React compartilhados. Componentes de formulário são clientes (estado local + `fetch` para a API); cabeçalho, logo e primitivos de UI servem a páginas servidor. Navegação usa `Link`/`useRouter` de `@/i18n/navigation` para preservar o locale.

## Summary

- ui.tsx — primitivos: Button, Input, Textarea, Select, Checkbox, Field, Card, Badge, Alert, PageHeader, Spinner
- AppHeader.tsx — cabeçalho com variantes "marketing" (público) e "app" (autenticado, com nav e logout)
- Logo.tsx — marca do app com link para a home
- LangSwitcher.tsx — troca de idioma (mantém o caminho, troca o prefixo de locale)
- AuthForm.tsx — login e registro (mesmo componente, `mode`)
- ForgotPasswordForm.tsx — POST `/api/auth/forgot`; nunca revela se o e-mail existe
- ResetPasswordForm.tsx — POST `/api/auth/reset`; sucesso redireciona ao login com aviso
- LogoutButton.tsx — POST `/api/auth/logout` e recarrega
- StudentManager.tsx — lista/busca de alunos e modal de criação (POST `/api/students`)
- AssignDialog.tsx — envio de treino para aluno (lista alunos, POST `assign`)
- BillingCard.tsx — cota do mês e planos pagos (POST `/api/billing/checkout`)
- wizard/ — orquestração do wizard de treino
- admin/ — componentes do painel administrativo

## Constraints

- Links e redirecionamentos de página MUST vir de `@/i18n/navigation` (não de `next/navigation`), sob pena de perder o prefixo de idioma.
